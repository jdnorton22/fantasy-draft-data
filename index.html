Powered by VBD Scoring

FFL Draft Day Picker uses Value Based Drafting (VBD) with projected points to rank every player. VBD measures each player's value relative to replacement-level talent at their position — so you're drafting based on true positional advantage, not just raw stats or name recognition.

Combined with real-time ADP tracking, the result is a scoring engine that tells you exactly when a player is a steal, a fair pick, or a reach. No guesswork.

FAQ

How does the VBD scoring work?
The app calculates Value Based Drafting scores using projected points for the upcoming season. Each player's value is measured against a replacement-level baseline at their position, so you see true positional advantage — not just raw point totals.
Does it work offline?
Yes — 100%. All player data is bundled. The AI advisor, pick grading, and draft tracking all run on-device with no internet required. Perfect for draft parties.
Can I use it for keeper or superflex leagues?
Yes. Configure 1–10 linear keeper rounds, then serpentine for the rest. The new QB Flex setting puts a premium on QB for superflex formats.
Is it really free?
Free, ad-free, no account, no data collection. Built by a fantasy football fan for fantasy football fans.
